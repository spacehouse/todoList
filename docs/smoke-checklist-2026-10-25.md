## A. 材料反推预览与生成（E11-E15）

- [ ] **A1 入口与横向树（E13）**：任务列表底部快速新增行点「材料」按钮 → 选目标物品（建议「铁块」，数量 8）→ 打开「材料配方预览」：从左到右分层，目标在最左、功能方块节点插在物品与材料之间；默认只展开一层；滚轮纵向、Shift+滚轮横向、空白处拖拽均可滚动，内容不越界
- [ ] **A2 展开与收起（E13）**：点「铁锭」节点名称区域 → 展开下一层（粗铁/深层矿）；再点一次 → 收起；「熔炼类输入」节点也可展开/收起；无配方 / 循环 / 达到上限的节点点不动，悬浮提示说明原因（E14⑤）
- [ ] **A3 功能方块节点与配方切换（E13/E14）**：功能方块节点有底、有框、带可切换标记，与物品节点视觉可区分；对有多条配方的物品（如「石头」有切石多条）点功能方块图标 → 切到下一条配方，方块与下级材料随之变化
- [ ] **A4 循环配方不卡死（E14④）**：选「雪块」类有互转配方的目标（4 雪球 ↔ 雪块）→ CYCLE 节点保留配方、功能方块不消失，可继续切换配方绕开环，界面不冻结
- [ ] **A5 浮层不被遮挡（E15①）**：对多候选输入的节点（tag 类，如木板原料）点物品图标 → 弹出「可选材料」列表；列表与悬浮提示不被树上的物品图标压住，被点的那颗图标自身也不会连带消失；选中候选后整树重算
- [ ] **A6 首列长名不裁切（E15②）**：目标物品选一个名称较长的物品（如下界合金锭 / 远古残骸）→ 首列名称完整显示，不被面板左缘裁掉
- [ ] **A7 全树同物品去重（E11）**：目标选「木镐」并把「木棍」分支展开（木棍 ← 木板×2，而木板同时是直接材料）→ 预览与生成的任务里**木板只出现一条**，数量取两处需求汇总；不出现两条木板任务
- [ ] **A8 收集语义与标题（E12）**：生成「铁块 ×8」两层树的任务 → 标题形如「合成 `[铁块]` ×8」「熔炼 `[铁锭]` ×72」「收集 `[粗铁]` ×72」（动作词 + 产物图标 + 数量，**不含功能方块**）；全部挂收集触发器：把粗铁凑够 → 该任务自动完成，且**不需要真的熔炼/合成**（拿到即达成）
- [ ] **A9 只按展示树生成（E13）**：收起某分支后再生成 → 该分支按最终材料生成一条收集任务，不生成其下级任务；数量输入与生成/取消按钮正常
